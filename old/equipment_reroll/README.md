# 장비 리롤 기능 백업

2026-10-09 장비 리롤 기능을 앱에서 제거하기 직전의 원본입니다.
공식 게임 기능으로 대체되어 현재 앱에서는 사용하지 않습니다.

- `src/equipment_reroll_bot.py`: 리롤 자동화와 숫자 판독 코드
- `src/gui.py`: 리롤 탭, 설정, 실행·중지, 통계 처리가 포함된 전체 GUI 원본
- `images/equipment_options/`: 리롤 버튼과 옵션 인식 이미지
- `tests/`: 리롤 전용 테스트 및 리롤과 연결된 공통 테스트의 원본
- `build_support/release_assets.py`: 제거 전 배포 이미지 목록
- `README.original.md`: 제거 전 앱 사용 안내

공통 파일은 당시 맥락을 보존하기 위한 전체 스냅샷입니다. 현재 파일을
이 백업으로 덮어쓰면 다른 기능의 후속 변경도 되돌아갈 수 있습니다.
백업은 현재 앱에서 가져오거나 배포하지 않으며, 활성 테스트 수집 대상도 아닙니다.
