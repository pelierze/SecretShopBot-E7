# 상점 구매 — 전체 화면 원본

상점 구매 기능의 전체 화면 원본 폴더입니다. GUI에서 옵션을 켜면 미래 투자만 구매하며, 기본값은 구매 없이 떠나기입니다.

1280×720 / DPI 240의 전체 화면을 PNG로 저장해주세요. 자르거나 크기를 변경하지 않은 원본을 넣습니다. 파일명은 아래 권장 이름 또는 기존 스크린샷 이름을 사용해도 됩니다.

| 권장 파일명 | 필요한 화면 |
|---|---|
| `01_shop_items.png` | 상품 목록, 가격, 보유 재화, 나가기 버튼이 보이는 상점 |
| `02_item_selected.png` | 상품을 선택한 직후의 상세 화면 또는 구매 확인 창 |
| `03_purchase_complete.png` | 구매 직후의 품절 표시, 재화 변화, 상품 배치 |
| `04_insufficient_currency.png` | 재화 부족으로 구매할 수 없는 상태 또는 안내 팝업 |
| `05_blocked_item.png` | 기존 금지 품목이 상점에 진열된 화면 |
| `06_excluded_item.png` | 추가로 구매 대상에서 제외할 상품이 진열된 화면 |
| `07_shop_exit.png` | 상점 나가기 및 확인 창 |

가능하면 같은 구매 과정을 전후 순서대로 남겨주세요. 여러 사례는 `_01`, `_02` 접미사로 구분합니다. 상품 선택만으로 즉시 구매되는지, 별도 확인이 필요한지도 함께 알려주세요.

잘라낸 버튼·상태 이미지는 [상점 템플릿 폴더](../../templates/shop/README.md)에 넣습니다. 기존 금지 품목 이미지는 `templates/blocked_choices/`를 재사용하므로 복사할 필요가 없습니다.

이 폴더에 저장하는 것만으로 구매 기능이나 이미지 인식이 활성화되지는 않습니다. 준비용 이미지는 배포에서 제외하고 실제 코드·설정에서 참조한 이미지부터 포함합니다.

## 미래 투자 실기 자료

- `shop_full.png`: 사용자가 제공한 전체 화면. 기존 상점 인식 원본의 이동 경로도 이 파일로 연결했습니다.
- `future_investment_available.png`: 구매 전, 파편 223 / 미래 투자 수량 10.
- `future_investment_confirm.png`: 미래 투자, 파편 50 구매 확인 창.
- `future_investment_purchased.png`: 구매 완료, 파편 173 / 미래 투자 수량 11.

구매 후 같은 상점에서는 반복 구매할 수 없고, 다음 상점에서 다시 구매할 수 있습니다. 기존 금지 상품인 별의 서가 함께 진열된 상태에서 미래 투자만 구매했습니다.

## 재화 부족 자료

- `shop_not_enough.png`: 보유 파편 22, 가격 50의 빨간 숫자 표시. 다른 상품의 가격 색과 구분해 미래 투자 가격 영역만 확인합니다.
- `shop_not_enough_message.png`: 클릭 시 하단에 나타나는 `차원의 파편이 부족하여 구매할 수 없습니다.` 안내. 닫기 버튼이 있는 팝업이 아니라 일시적인 안내입니다.

빨간 가격 또는 부족 안내가 보이면 숫자 OCR에 의존하지 않고 구매를 건너뜁니다. 상품 선택/구매 확정 이후 부족 안내가 나타나도 재클릭하지 않으며 구매 횟수를 증가시키지 않습니다. 기존 보유 파편·가격 비교도 유지합니다.
