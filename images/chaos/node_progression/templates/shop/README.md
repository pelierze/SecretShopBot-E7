# 상점 구매 — 인식용 이미지

전체 원본은 [raw/shop](../../raw/shop/README.md)에 보관하고, 잘라낸 버튼·상태 이미지는 이 폴더에 넣습니다. 전체 원본만 준비해도 됩니다.

| 권장 파일명 | 내용 |
|---|---|
| `purchase_button.png` | 구매 가능한 버튼 |
| `purchase_button_disabled.png` | 구매 불가 버튼 |
| `purchase_confirm.png` | 구매 확정 버튼 |
| `purchase_cancel.png` | 구매 취소 버튼 |
| `sold_out.png` | 품절 표시 |
| `insufficient_currency.png` | 재화 부족 안내의 고유 문구 |
| `excluded_product_marker.png` | 별도로 구매에서 제외할 상품의 공통 식별 표시 |

실제로 표시되는 항목만 준비해주세요. 서로 다른 팝업에 같은 확인 버튼이 쓰이면 팝업 고유 문구와 전체 원본도 함께 남깁니다. 변동 가격·재화 숫자나 상품 배경이 버튼 이미지에 과하게 포함되지 않도록 합니다.

기존 금지 품목은 [공통 금지 이미지 폴더](../blocked_choices/)를 그대로 사용합니다. 상점에서 크기나 배경이 다르면 해당 전체 화면을 `raw/shop/`에 남겨 인식 가능 여부를 먼저 확인합니다.

`future_fund.png`는 상품의 실제 이름에 맞춰 `future_investment.png`로 변경했습니다. 현재 연결된 유일한 구매 상품은 **미래 투자**입니다. 인식에는 가격을 제외한 상품명·아이콘 영역을 사용하고, 가격은 화면에서 별도로 읽습니다.

GUI의 `미래 투자만 구매 (상점마다 1회)` 옵션은 기본 OFF입니다. 상품·가격·보유 파편 확인 → 구매 확인 창의 상품명과 금액 재확인 → 구매 → 구매 완료 표시와 파편 차감 확인 → 상점 퇴장 순서로 진행합니다. 미진열·기구매·재화 부족이면 건너뛰며 다른 상품이나 투자금 인출은 선택하지 않습니다.

미사용 이미지는 배포 파일에 포함하지 않습니다.
