# 자동 탐사 — 영웅 선택 단계 이미지

테마 선택부터 네 직업의 영웅 선택 완료까지 사용하는 자료를 준비하는 공간입니다. 현재 등록 조합은 그림자 로제, 불사형 오공, 데스티나, 제뉴아입니다. 탐사 진입 화면은 다음 단계로 넘어갔는지 확인하는 용도로 함께 보관합니다.

현재 네 직업의 영입 흐름은 앱에 연결되어 있습니다. 실제 사용 파일과 원본 영역은 `src/chaos/recruitment_layout.json`에 명시합니다. 새 이미지를 폴더에 넣는 것만으로 후보가 자동 등록되지는 않습니다.

## 폴더 구성

| 경로 | 넣을 자료 |
|---|---|
| `raw/` | 자르거나 수정하지 않은 전체 화면 스크린샷 |
| `templates/themes/` | 테마·난이도 선택에 필요한 인식용 이미지 |
| `templates/heroes/` | 지정 기사와 커스텀 영웅을 식별하는 인식용 이미지 |
| `templates/controls/` | 필터, 선택, 확인, 진입 등 조작 대상 이미지 |
| `templates/states/` | 영웅 선택 화면, 선택 완료, 다음 단계 진입 등 상태 확인 이미지 |

처음에는 **전체 스크린샷을 `raw/`에 순서대로 넣는 것만으로 충분합니다.** 인식용 이미지의 잘라낼 영역은 실제 절차를 확인하면서 정합니다.

## 준비할 화면

- 테마와 난이도를 선택하는 화면 및 선택 후 화면
- 지정 기사를 고르는 화면 및 선택 후 화면
- 커스텀 영웅을 찾는 데 사용하는 목록·필터·검색 화면
- 커스텀 영웅 각각을 선택하기 전과 후의 화면
- 4명 모두 선택된 상태와 완료/확인 버튼이 보이는 화면
- 선택 확정 후 탐사 진입 화면
- 가능하다면 필요한 영웅이 없는 목록이나 선택 불가 상태

실제 게임 화면 순서에 맞춰 준비합니다. 아직 확인하지 않은 버튼이나 절차가 있다고 가정하지 않습니다.

## 이름 규칙

폴더는 단계 이름인 `hero_selection`을 사용합니다. 나중에 진행 순서가 바뀌어도 폴더명을 바꿀 필요가 없도록 단계 번호는 경로에 넣지 않습니다.

- 파일명은 영어 소문자, 숫자, 밑줄로 작성합니다.
- 원본은 `순서_화면설명.png` 형식을 권장합니다. 예: `010_theme_screen.png`, `020_hero_list.png`, `030_party_complete.png`. 번호는 실제 화면 순서에 맞춰 정합니다.
- 인식용 이미지는 용도와 상태를 드러냅니다. 예: `confirm_button_enabled.png`, `party_complete_indicator.png`.
- 영웅 이미지는 `기사1`, `영웅2` 같은 슬롯 번호 대신 실제 영웅의 고유 이름을 사용합니다. 직업과 구성 내 역할은 아래 이미지 목록에 기록합니다.
- 선택 전·후 이미지가 모두 필요하면 `_unselected`, `_selected`로 구분합니다.
- 같은 대상의 다른 모습을 보관할 때는 `_list`, `_portrait`처럼 차이를 적습니다. 의미를 알 수 없는 `_1`, `_2`, `_final`은 피합니다.

위 파일명은 예시이며 실제 이미지나 동작이 등록된 것은 아닙니다.

## 촬영 및 잘라내기 기준

- 기존 앱 기준인 **1280×720, DPI 240**으로 준비합니다. 다른 환경에서 촬영했다면 해상도와 DPI를 기록합니다.
- 원본은 확대·축소, 표시선 추가, 잘라내기 없이 보관합니다. 설명과 표시가 필요하면 별도 사본을 사용합니다.
- 인식용 PNG는 원본 해상도에서 필요한 영역을 잘라 저장하고, 크기 변경이나 손실 압축은 하지 않습니다.
- 커서, 전환 효과, 깜빡임이 사라진 안정된 화면을 촬영합니다.
- 버튼 인식과 클릭 위치, 상태 확인은 서로 다를 수 있습니다. 이미지가 발견됐다는 이유만으로 클릭 가능한 대상으로 취급하지 않습니다.
- 인식용 이미지가 없어도 원본과 화면 설명을 먼저 추가할 수 있습니다.

## 교체·유지보수

새 후보는 `recruitment_layout.json`의 `heroes`에 이름·직업·속성과 목록/선택/완료 마커를 등록하고 `markers`에 해당 파일과 영역을 연결합니다. GUI 후보 목록은 이 설정에서 읽습니다. 기존 후보의 대소문자나 `warrier` 철자를 수정할 필요는 없으며 파일 경로를 정확히 연결하면 됩니다.

1. 변경된 화면의 원본을 먼저 추가하고 촬영 환경과 변경 이유를 아래 이력에 적습니다.
2. 관련 인식용 이미지를 갱신하고 이미지 목록의 원본·영역도 함께 수정합니다.
3. 선택 전·후 상태와 다른 영웅/버튼에 대한 오인식 여부를 확인합니다.
4. 실제 이미지 로더 연결 이후에는 파일 이름이나 경로 변경 시 참조 설정도 함께 수정합니다.

Git에 등록된 이미지의 이전 버전은 Git 이력으로 관리합니다. 이전 파일을 덮어쓰기 전에는 해당 파일이 커밋되어 있는지 확인합니다. 기존 `images/chaos/`와 `images/chaos/raw/`의 자료는 검토 후 필요한 항목만 이 구조로 옮기거나 복사하며, 현재는 그대로 유지합니다.
