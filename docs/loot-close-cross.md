# 전리품 팝업의 닫기 아이콘 인식

2026-10-09 15:56:33 로컬 오류 보고서에서 미등록 이벤트 선택 후 차원핵
전리품 팝업이 표시됐지만, 닫기 문구 매칭 점수 0.6221로 기준 0.92에
미달해 이벤트 선택 결과 확인이 시간 초과됐다.

최신 보고서 하단의 `×` 아이콘만 `(584, 684, 20, 20)` 영역으로 검사한다.
기존 탐색 영역 `(550, 665, 180, 50)`, 일치도 0.92와 색상 오차 0.07을
유지한다. 최신 화면은 1.0000, 기존 전리품 팝업은 0.9807로 통과하고
기존 화면의 색상 오차는 0.0269이다. 클릭은 인식한 아이콘 중심에서
수행하며 기존 팝업 닫힘 확인 및 제한된 재시도 흐름을 유지한다.

전리품 이름과 닫기 문구에 의존하지 않는다. 최신·기존 전리품 팝업,
문구 및 이름 가림, 아이콘 제거와 일반 지도·휴식·보상·레벨업 화면을
검증했다. 닫기 재시도, 이벤트 전환, 전리품 수령, 상점 보상 및 배포 리소스를
포함한 관련 테스트 60개가 통과했다. 실제 게임에서 이벤트 후속 진행은
추가 실행 확인이 필요하다.
