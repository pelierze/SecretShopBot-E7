# 휴식 랭크업 항목의 글자 인식

2026-10-09 15:48:07 로컬 오류 화면에서 휴식 화면 판별은 성공했지만,
전체 안내 문구를 사용한 랭크업 항목 매칭은 0.6038로 기준 0.90에 미달했다.

사용자가 요청한 대로 `랭크` 두 글자만 37×26 영역으로 검사한다. 최신
보고서에서 `(987, 184, 37, 26)`을 가져오며 기존 탐색 영역, 매칭 기준
0.90과 색상 오차 기준 0.055는 유지한다.

최신 활성 화면의 일치도는 1.0000이다. 기존 활성 화면에서는 일치도
0.9410, 색상 오차 0.0465로 통과한다. 사용 완료 화면은 글자 모양이
같아 일치도 0.9410이지만 색상 오차 0.1763으로 거부한다. 따라서
색상 오차 검사는 비활성 랭크업을 다시 누르지 않기 위해 유지한다.

실제 화면의 활성·비활성 상태, 글자 제거, 노드 상세 화면 및 배포
리소스를 검사하는 관련 테스트 10개가 통과했다. 실제 게임에서
랭크업 클릭과 후속 진행 확인은 추가 실행이 필요하다.
