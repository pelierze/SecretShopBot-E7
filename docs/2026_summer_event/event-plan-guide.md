# 2026 여름 이벤트 플랜 안내

이벤트 자동화는 원하는 보상 목표에 따라 네 가지 플랜을 제공합니다. 계획 목표에 도달하기 전에는 현재 위치와 보호·도움닫기·슈퍼럭키 잔량을 함께 계산해 목표 도달 확률이 가장 높은 행동을 선택합니다.

## 어떤 플랜을 선택해야 하나요?

| 플랜 | 추천 대상 | 운용 목표 |
|---|---|---|
| 100M | 100M 보상을 가장 안정적으로 받고 싶은 사용자 | 아이템을 적극적으로 활용해 100M 도달을 우선하고, 달성 후 200M 최적 경로로 이어갑니다. |
| 200M | 반복 가능한 핵심 보상을 꾸준히 모으고 싶은 사용자 | 100M·200M 보상 획득 안정성을 중시하고, 200M 달성 후 300M 최적 경로로 이어갑니다. |
| 300M | 중간 보상이 줄어도 더 높은 가치의 300M 보상을 원하는 사용자 | 앞 구간의 일부 안정성을 포기하고 아이템을 후반에 배분해 300M 도달 가능성을 높입니다. |
| 500M 고점 모드 | 반복 효율보다 500M 초회 보상을 노리는 사용자 | 전체 아이템과 충전 지점을 계산해 500M 단일 도달 확률을 최대화하며, 도달하면 자동으로 중지합니다. |

## 현재 기준 예상 도달 확률과 소비량

아래 수치는 앱에 포함된 2026-08-03 확률 데이터와 0~290M 누락 구간의 보간값을 이용한 이론값입니다.

| 플랜 | 단일 시도 목표 도달 확률 | 성공 1회까지 예상 총 음료수 |
|---|---:|---:|
| 100M | 약 100.00% | 약 8.00개 |
| 200M | 약 61.24% | 약 21.62개 |
| 300M | 약 8.55% | 약 121.79개 |

`성공 1회까지 예상 총 음료수`는 동일한 조건으로 실패 후 다시 도전한다고 가정하고, 실패한 시도에서 사용한 음료수까지 모두 합산한 기대값입니다.

500M 고점 모드는 300M 이후 실제 확률 데이터가 아직 없어 예상 도달 확률과 음료수 소비량을 게시하지 않습니다. 후반 실제 표본이 충분히 쌓인 뒤 별도로 갱신합니다.

## 확률을 해석할 때 알아둘 점

- 이 확률은 게임 이동 결과만 계산한 이론값이며 화면 인식 실패, 네트워크 문제, 음료수 부족은 포함하지 않습니다.
- 0~290M는 제공된 확률과 그 사이 구간의 보간값을 사용합니다.
- 300M 이후는 아직 실제 표본이 부족해 앱 내부 경로 계산에서만 앞 구간의 확률 흐름을 예측값으로 사용합니다.
- 앱은 미등록 구간의 화면 확률을 동일 값 3회 확인한 뒤 개인 데이터로 확정합니다.
- 이동 성공·실패 결과도 사용자 장치에 누적되며 다음 이벤트 실행을 시작할 때 경로 계산에 반영됩니다.
- 실행 중에는 새 데이터가 생겨도 경로를 반복 계산하지 않아 동작 지연을 줄입니다.
- 각 목표에서는 도달 확률을 가장 먼저 높이고, 확률이 같은 경로끼리는 예상 음료수 사용량이 적은 경로를 선택합니다.

## 목표 달성 후 동작

표준 플랜은 선택한 목표에 도달했다고 즉시 멈추지 않습니다.

```text
100M 플랜: 100M 최적 경로 → 200M 최적 경로 → 300M 최적 경로
200M 플랜: 200M 최적 경로 → 300M 최적 경로
300M 플랜: 300M 최적 경로 → 남은 아이템으로 추가 보상 시도
500M 고점 모드: 500M 최적 경로 → 도달 즉시 중지
```

300M 이후 표준 플랜은 별도의 350M·400M 확률 경로를 다시 계산하지 않고 `슈퍼럭키 → 보호 → 도움닫기 → 기본 이동` 순서로 추가 보상을 시도합니다.

일반 이동이나 도움닫기에 실패하면 획득한 보상은 유지되고 위치와 시작 아이템이 초기화됩니다. 보호 실패는 현재 위치를 유지하면서 보호 1개만 소비하며, 남은 아이템 상태에 맞는 후속 행동을 이어갑니다.

## 간단한 선택 가이드

- 핵심 보상을 반복해서 모으는 것이 우선이라면 `200M 플랜`
- 반복 보상 횟수가 줄어도 300M 고가치 보상을 노린다면 `300M 플랜`
- 500M 초회 보상을 아직 받지 못했다면 `500M 고점 모드`
- 짧고 안정적인 진행을 원한다면 `100M 플랜`

확률 데이터와 개인 관측이 갱신되면 예상값과 실제 선택 경로는 달라질 수 있습니다.
