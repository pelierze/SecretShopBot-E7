# 보급 항목의 전리품 글자 인식

2026-10-09 17:20:18 로컬 보고서에서 보급에 진입했지만 전체 안내 문구의
일치도 0.6028로 보급 화면 판정에 실패했다. 떠나기 버튼만 인식되어
휴식 화면으로 분류됐고, 보급 진입 확인이 시간 초과됐다.

사용자 요청대로 `전리품` 세 글자만 `(930, 402, 55, 28)` 영역으로 검사한다.
최신 보고서를 기준으로 삼고 기존 탐색 영역, 일치도 0.85, 색상 오차 0.10을
유지한다. 최신 화면은 1.0000으로 매칭되어 보급으로 판별된다. 기존 활성
화면은 일치도 0.8865와 색상 오차 0.0605로 통과한다. 획득 후 비활성 항목은
일치도 0.8866이지만 색상 오차 0.1791로 거부된다.

최신·기존 활성 화면, 획득 완료 상태, 글자 제거, 휴식·상세·지도 화면 및
배포 리소스를 검증한다. 보급 항목이 인식되면 기존 분류 순서에서 휴식
판정보다 먼저 보급으로 처리한다. 실제 게임 후속 진행은 추가 실행 확인이
필요하다.
