# 전리품 소모창의 슬롯 + 인식

2026-10-09 21:13:45 종료 보고서는 전리품 1개 소모 선택창이다.
기존 안내 문구의 일치도는 0.3533으로 인식되지 않았고, 가려진
이벤트 선택지로 재분류되어 허용 후보 없음으로 중지됐다.

빈 슬롯은 지정된 중앙 영역의 밝고 채도가 낮은 픽셀에서 + 모양을
확인한다. 가로와 세로 획의 길이, 중심 위치, 채움 비율을 검증하며
문구 이미지나 슬롯 테두리를 사용하지 않는다. 오른쪽 전리품 목록의
아이콘 배치가 함께 검출돼야 소모창으로 인정한다. 숫자, X, 사각형,
가로선, 테두리만 남은 빈 슬롯은 이 빈 슬롯 조건을 만족하지 않는다.

전리품을 선택하면 +가 사라지므로 슬롯 왼쪽 위 삭제 X와 전리품
목록을 확인하는 보조 경로를 사용한다. 이 경로는 기존 선택 완료
화면의 삭제 X 이미지를 참조한다. 실제 소모 확정에는 기존의 대상
아이콘 일치와 선택 수량 1/1 검사를 유지한다. 금지 전리품 우선 소모
정책도 유지한다.

최신 보고서 복사본은 회귀 자료로 사용하고 배포에서는 제외한다.
삭제 X 확인에 쓰는 기존 선택 완료 이미지는 배포 자산에 포함한다.
실제 게임에서 소모 확정 및 이벤트 후속 진행은 다음 실행에서
확인해야 한다.

검증: 최신 오류 화면, 문구·배경 변경, 유사 모양 거부, 선택 후 인식,
이벤트 보상 처리 및 배포 자산 검사 20개 통과.
