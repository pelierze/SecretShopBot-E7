# Issue #14: 영입 목록에서 필터 확인 시간 초과

## 제보와 재현

[이슈 #14](https://github.com/pelierze/SecretShopBot-E7/issues/14)의 v1.5.11
보고서와 스크린샷을 확인했다. 영입권 입력 후 기사 영웅 목록에서
`목록 및 필터 버튼 확인` 대기 시간이 초과됐다. 그림자 로제와 모험가 라스에서
시간 초과가 기록됐고 아로웰에서도 같은 단계에서 사용자가 중지했다.

필터 버튼은 매칭 0.9646, 색상 오차 0.0195로 정상 인식됐다.
기존 기사 제목은 매칭 0.9305지만 색상 오차 0.0551이 허용치 0.035를
초과해 거부됐다. 제목 조건이 실패하여 실제 필터 버튼 확인도 실패했다.
색상 검사만 제거하면 기존 전사 제목도 기사 제목과 0.9029로 매칭돼
현재 0.90 기준에서 잘못 통과한다.

## 변경

캐릭터 이름 왼쪽 직업 아이콘을 28×28 크기로 잘라 네 종류의 템플릿으로
저장했다. 기사 방패, 전사 검, 정령사 지팡이, 도적 후드 얼굴을 사용한다.
제목을 확인하던 조건은 목록 영역 `(345, 80, 935, 515)`에서 해당 직업 아이콘을
찾도록 변경했다. 기존 설정 키와 호출 흐름은 유지한다.

직업 아이콘은 클릭 대상이 아닌 화면 확인용이므로 동일 아이콘이 여러 개
나오는 것을 허용하고 별도 색상 오차 검사를 적용하지 않는다. 매칭 기준은
0.90으로 유지한다. 필터 버튼, 필터 메뉴, 영웅 선택 및 영입 버튼 등의
입력 조건과 색상 검사는 그대로 유지한다.

## 검증

기존 영입 화면과 제보 화면 18개에서 직업을 구분했다. 제보의 기사 아이콘은
1.0000으로 일치했고 다른 직업과의 최대 매칭은 0.4563이었다.
제보 화면은 `images/chaos/hero_selection/raw/knight_issue14_live.png`에
회귀 자료로 저장했고, 배포 이미지 목록에서는 제외한다. 신규 아이콘 4개는
배포 패키지에 포함한다.

직업 아이콘, 영입·대체 영웅 흐름, 배포 파일과 업데이트 버전 검사 45개 및
기사 영입·서약서 선택·아이콘 검사 25개가 통과했다. 두 실행에는 아이콘
테스트 6개가 중복 포함된다. 제목 없는 화면, 여러 아이콘, 아이콘 없는 목록,
다른 직업·영입권 카드 화면을 확인했다.

실제 제보 PC의 전체 탐사 실행은 확인하지 못했다. v1.5.12 실행 파일에
변경을 포함하며, 설치 후 자동 탐사를 다시 시작해야 적용된다.

배포 패키지의 템플릿과 설정을 로드해 제보 화면의 필터 확인 통과를 확인했다.
직업 아이콘 4개와 업데이터가 ZIP에 포함되며, 제보 원본·로그·테스트는
포함되지 않는다. 실행 파일의 Windows 버전은 1.5.12이고 ZIP 체크섬도 일치한다.
