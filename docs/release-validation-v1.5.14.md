# v1.5.14 배포 검증 기록

- 등록 이벤트, 이벤트 모드·후속 보상, 랭크업 완료, 영웅 보상 건너뛰기, GUI·스크롤 및 배포 자산 관련 119개 테스트를 실행했다.
- 처음 118개 통과, 1개는 등록 이벤트에서 무작위 선택이 호출되지 않는 이전 동작을 기대했다. 새 동작에 맞춰 수정하고 해당 다단계 이벤트·전리품·영웅·랭크업·지도 복귀 시나리오를 재실행해 통과했다. 최종 미해결 실패 없음.
- 모든 등록 이벤트의 기존 캡처에서 공통 버튼 후보와 무작위 선택을 검증했다. 최신 09:27 서재 오류 캡처에서도 문구 규칙 호출 없이 선택이 가능하다.
- 최신 오공 및 기존 도적 랭크업 완료 캡처를 인식한다. 문구·초상화 가림과 필수 아이콘·버튼 누락도 확인했다. 기사·정령사 전투 완료의 실제 캡처는 아직 없으며 기존 공통 직업 아이콘을 사용한다.
- 종료된 이벤트 원본 30개를 보관 폴더와 기존 Git 내용의 해시로 비교해 보존을 확인했다. 원본 이미지도 Git에서 누락되지 않도록 제외 규칙을 조정했다.
- `build_release.ps1 -Version v1.5.14` 빌드와 배포 폴더 검증 통과. 앱·업데이터 실행 파일, ZIP 및 SHA256 파일 생성 완료.
- `git diff --check` 통과. 실제 게임의 수정 후 연속 실행은 아직 수행하지 않았다.

상세 로그: `release/v1.5.14-tests.log`, `release/v1.5.14-event-chain-retest.log`, `release/v1.5.14-build.log`.
