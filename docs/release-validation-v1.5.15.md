# v1.5.15 배포 검증 기록

- 랭크업 보상은 제목 문구 대신 카드 상단 70×76 아이콘으로 분류한다. 이슈 16번과 로컬 오류 캡처의 일치도는 각각 0.9999이며, 제목·설명 문구를 가려도 인식한다.
- 아이콘 또는 하단 버튼 누락, 다른 보상과 랭크업 완료 화면은 보상 진입으로 판정하지 않는다. 입력 직전 랭크업 버튼 재확인 및 후속 보상 처리는 유지한다.
- 업데이트·저장소 전환·릴리즈 조회·GUI·업데이트 안내·JSON 매크로·랭크업·이벤트 보상·배포 자산 관련 113개 테스트 모두 통과했다.
- 이름 전환 준비 변경도 포함한다. 기존 ZIP과 실행 파일 이름을 유지하고, 기존·새 공식 저장소와 이름의 다운로드·검증·설치·복구 동작을 모의 응답 및 파일 시나리오로 검증했다. 실제 저장소 이름 변경은 수행하지 않는다.
- `build_release.ps1 -Version v1.5.15`로 앱 및 자동 업데이트 실행 파일을 빌드하고 배포 폴더 검증을 통과했다.
- `git diff --check` 통과. 새 빌드의 실제 게임 연속 실행과 배포본 간 자동 업데이트는 아직 직접 수행하지 않았다.

상세 로그: `release/v1.5.15-tests.log`, `release/v1.5.15-build.log`.
