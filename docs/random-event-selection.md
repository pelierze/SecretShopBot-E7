# 미등록 이벤트 선택 방식 정리

미등록 이벤트의 문구 판단 옵션과 OCR 기반 효과 해석 경로를 제거했다.
GUI는 무작위 선택만 제공하고, 실행 시에도 무작위 방식을 전달한다.
탐사 객체의 기본값은 random이며 기존 호출에서 ocr를 전달하더라도
무작위 방식으로 통일한다. 문구 판독기와 효과 우선순위 모듈은 제거했다.

등록된 이벤트는 기존 저장 규칙을 사용한다. 미등록 이벤트는
금지 이미지, 비활성 상태, 이전에 취소된 선택지를 제외한 후보에서
무작위로 선택한다. 선택지 배치와 화면 변경을 클릭 직전에 다시
확인하고 실제 결과 화면으로 전환됐는지 확인하는 검사는 유지한다.
미확인 이벤트 저장 옵션과 비정상 종료 진단 기록도 유지한다.

검증: 이벤트 모드, 등록 이벤트, 반복 처리, GUI 및 배포 자산 검사
75개를 확인했고, 변경된 동작에 맞춰 수정한 3개 항목도 재실행해 통과했다.
