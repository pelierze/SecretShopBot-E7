# 움직이는 레벨업 닫기 화살표 인식

2026-10-09 15:40:34 로컬 보고서에서 첫 전투는 승리했으나 레벨업 팝업을
인식하지 못해 전투 제한 시간이 만료됐다. 기존 닫기 안내 문구의 이미지
매칭 점수는 0.6132로 기준 0.85에 미달했다.

닫기 안내 문구 대신 하단의 아래 방향 화살표를 사용한다. 최신 보고서의
28×23 화살표를 원본으로 삼고, 화면 `(590, 635, 100, 65)` 영역에서 탐색한다.
기존 0.90~1.10 배율 검사를 유지하며 화살표의 이동을 허용한다. 레벨업 제목과
화살표가 같은 배율에서 각각 하나씩 인식되고 서로 정렬되어야 팝업으로
판정한다. 제목만 있거나 화살표만 있는 화면에서는 닫기 입력을 허용하지 않는다.

연속 화면 안정화와 클릭 직전 재확인에는 화살표 좌표 대신 고정된 닫기 영역
`(582, 624, 116, 28)`을 반환한다. 화살표는 매 화면에서 새로 확인하므로
애니메이션에 의해 관측 좌표가 달라져도 안정화가 실패하지 않는다. 입력은
기존 팝업 닫기 영역 중심에서 수행하며 닫힘 이후 화면 확인과 제한된 재시도
절차를 유지한다.

최신 오류 화면과 기존 레벨업 화면에서 정상 인식을 확인했다. 화살표를
상단 좌표 635·645·658·675로 이동한 화면, 닫기 안내 문구 가림, 제목 또는
화살표 누락, 배율 변경, 이동 중 클릭 직전 재확인, 전투 대기 탈출을 검증했다.
관련 팝업·배포 리소스 테스트 28개가 통과했다. 실제 게임의 다음 실행은
추가 확인이 필요하다.
