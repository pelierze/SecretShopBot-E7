# 전투 랭크업 완료: 직업 아이콘과 탐사하기 버튼

2026-10-10 00:57:25 보고서에서 불사형 오공의 랭크업은 성공했으나 완료 문구의 이미지 일치도가 0.6952로 기준 0.90에 미달했다. 승리 화면으로 분류되어 랭크업 결과 대기가 시간 초과됐다.

완료 문구 대신 카드 우하단의 직업 아이콘을 확인한다. 전사와 도적은 전투 완료 캡처, 기사와 정령사는 기존 영입 완료 카드의 공통 직업 아이콘을 사용한다. 검색 영역은 카드 우하단 48×48, 아이콘 28×28, 일치도 0.90을 유지한다.

승리 표시와 하단의 탐사하기 글자도 함께 있어야 완료로 인정한다. 계속 탐사하기 이미지에서 앞의 계속 부분을 제외한 75×27 영역만 사용한다. 클릭은 인식된 글자 영역 안에서 수행하며 기존 입력 직전 재확인과 안정 프레임 검사를 유지한다. 영웅 이름·초상화·랭크업 완료 문구는 판정하지 않는다.

최신 전사 및 기존 도적 실제 캡처, 문구·초상화 가림, 필수 표식 누락, 다른 보상 화면, 완료 후 지도 복귀를 검증한다. 기사와 정령사의 전투 완료 실제 캡처는 아직 없다.

검증 명령: `test_chaos_rank_result.py`, `test_chaos_event_flow.py`, `test_chaos_reported_reward_flow.py`, `test_chaos_recruit_skip_confirm.py`, `test_release_assets.py`를 unittest로 실행했다. 결과 로그: `release/battle-rank-completion-tests.log`. 모두 통과했으며 실제 게임 연속 실행은 아직 확인하지 않았다.
