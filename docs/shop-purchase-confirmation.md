2026-10-09 18:00:32 로그는 미래 투자 선택 후 상품 불일치로 구매를
취소했다. 사용자 제공 구매 화면에서 구매 버튼은 0.9920으로 인식되며,
금액 50도 정상 판독됐다. 기존 상품 템플릿의 일치도는 0.7586으로
기준 0.9에 못 미쳤다. 아이콘과 상품명 사이의 배경까지 포함하는
234×75 영역 대신 미래 투자 아이콘 74×75 영역을 사용한다.
가격 변경, 재화 부족, 금지 상품, 구매 완료 및 파편 차감 검사는 유지한다.
구매 취소 시 해당 판단 이유를 로그에 기록한다.

18:02:13 비정상 종료의 직접 원인은 상점 퇴장 확인 시간 초과였다.
보고서 화면의 퇴장 문구는 기존 템플릿과 0.4430으로 일치했지만,
확인 및 취소 버튼은 각각 0.9973, 0.9836으로 인식된다.
검증된 상점 화면에서 앱이 직접 나가기를 누른 뒤에만 퇴장 확인
문맥을 시작한다. 이때 두 버튼이 함께 인식되면 상점 퇴장창으로
판단하며, 기존 팝업 닫기 로직의 안정 프레임 및 클릭 직전 검사를
거쳐 확인을 누른다. 지도 복귀, 시간 초과, 사용자 중지 등 어떤
종료 경로에서도 문맥을 해제한다. 문맥 밖의 경고창 분류는 유지한다.

사용자 원본 이미지는 유지하고 구매 및 퇴장 화면 복사본은 회귀
검사에 사용한다. 두 진단 화면은 배포 자산에 포함하지 않는다.
실제 게임 구매와 퇴장 동작은 다음 실행에서 확인해야 한다.

검증: 상점, 영웅 보상 건너뛰기, 팝업 닫기, 배포 자산 관련 테스트
39개 통과. 새 구매 화면에서 아이콘 일치도는 1.0000, 색상 오차는
0.0002다. 구매 버튼 입력부터 퇴장 확인 및 지도 복귀까지 재현했다.

## 구매 완료 이미지 의존 제거

2026-10-09 20:10:12 보고서는 미래 투자 카드가 구매 완료 상태이고
보유 파편이 173이지만, 완료 이미지 일치도가 0.8369라 구매 완료
검사에 진입하지 못했다. 구매 버튼 입력 후 성공 검사는 이 이미지에
의존하지 않고 상점 복귀와 보유 파편 차감으로 수행한다.

구매 전 잔액 표시는 상품 선택 직전 상점 화면에서 보관한다. 구매 후에는
잔액 OCR을 호출하지 않는다. 구매창이 닫힌 상점에서 잔액 영역의 밝고
채도가 낮은 숫자 획을 추출하고 구매 전 획과 비교한다. 빈 표시나
영역 대부분을 덮는 밝은 화면은 유효 숫자 표시로 인정하지 않는다.

변화가 12픽셀 이상이면서 두 획 영역의 합집합 대비 10% 이상이어야
변화로 인정한다. 이후 화면에서는 합집합의 3% 또는 3픽셀 이내의
작은 흔들림을 같은 표시로 묶어 기존 안정 프레임 검사에 전달한다.
한 프레임만 변화하거나 계속 다른 형태로 변하면 성공으로 계산하지
않는다. 재화 부족 안내와 중간 보상 팝업 처리는 유지한다.

잔액 표시가 유지되거나 가려지거나 구매창이 계속 열려 있으면 성공으로
기록하지 않는다. 구매 버튼은 다시 누르지 않으며 시간 초과 시 표시
변화량과 화면 상태를 로그에 남기고 진단 보고서를 저장한다. 이 방식은
정확한 차감 금액을 보증하지 않으며, 숫자 표시 변화와 상점 복귀를
구매 완료의 근거로 사용한다. 구매 전 상품·가격·보유량 검사는 유지한다.

이미 구매한 카드의 선택 전 검사에는 기존 완료 이미지가 남아 있다.
변경 범위는 구매 입력 후 성공 판정이며 전체 상점 화면 분류도 유지한다.
최신 보고서 복사본은 검사에 사용하고 배포 자산에서는 제외한다.

실제 게임의 다음 구매 실행에서 후속 진행 확인이 필요하다.

숫자 표시 변화 방식 검증: 상점 및 배포 자산 검사 21개 통과.
구매 후 OCR 미호출, 최신 보고서의 성공 판정, 배경 변화·소량 잡음·
가려진 숫자·열린 구매창·일시적인 변화·계속 흔들리는 표시의 거부와
구매 버튼 재입력 방지를 확인했다.
