# 이벤트 랭크업 보상 아이콘 인식

2026-10-11 이슈 16번과 로컬 10:22:15 보고서는 동일한 보상 카드 제목 인식 실패였다. 제목 일치도 0.7466이 기준 0.92에 미달했고, 랭크업 버튼과 계속 탐사하기 버튼은 정상 인식됐다.

기존 보상 캡처에서 제목 위 랭크업 아이콘만 70×76 크기로 잘라 사용한다. 검색 영역은 카드 상단 110×105, 기준 0.92와 색상 오차 0.055는 유지한다. 아이콘과 기존 하단 버튼이 함께 보여야 rank_reward로 분류한다. 제목·설명 문구는 분류에 사용하지 않는다. 실제 랭크업 버튼을 누르기 직전의 재확인과 이후 영웅 선택·랭크업 흐름은 유지한다.

두 오류 화면의 아이콘 일치도는 각각 0.9999다. 기존 보상 화면, 제목·설명 가림, 아이콘·하단 버튼 누락, 다른 보상 및 랭크업 완료 화면으로 검증한다. 오류 캡처는 테스트 자료로만 보관하며 배포에는 기존 원본 이미지의 아이콘 영역을 사용한다.

검증: 랭크업 결과·이벤트 보상 흐름·배포 자산 관련 37개 테스트 통과. 로그는 `release/event-rank-reward-icon-tests.log`에 보관한다. 실제 게임 연속 실행은 아직 확인하지 않았다.
