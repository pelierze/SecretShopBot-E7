- 환경: BlueStacks `emulator-5554`, 1280×720 / DPI 240

## 범위

초기 화면 → 탐사 시작 → 고용 서약서 선택 → 기사 → 전사 → 정령사 → 도적 순서로 진행했다. 실행 중 수동 입력 없이 완료했고, 마지막 네 카드의 영입 완료 표시와 지정 영웅 이름을 모두 확인했다. 탐사 입장 버튼은 누르지 않았다.

실제 GUI의 네 선택란에서 후보를 읽어 `PartyRecruitmentBot`에 전달했다. 실행 중 선택란이 비활성화되고 종료 후 편집 가능 상태로 복구되는 것을 확인했다. 1180×920 및 1000×760 창 크기에서 네 선택란의 배치도 확인했다. 테스트 창은 투명하게 실행했고 원격 업데이트 조회와 소리만 생략했다.

## 현재 한계

현재 네 영웅만 등록했다. 다른 후보는 이름·속성과 선택/완료 이미지 확인 후 `src/chaos/recruitment_layout.json`에 등록한다. 신규 해금 팝업은 코드와 재현 테스트로 다루지만 이번 실기에서는 나타나지 않았다. 노드 진행과 전투, 클리어 후 반복은 아직 구현 범위 밖이다. 배포용 실행 파일 빌드와 릴리즈 업로드는 수행하지 않았다.
