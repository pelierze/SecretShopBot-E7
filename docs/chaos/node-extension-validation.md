# 노드 실행 연결 검증 (2026-09-25)

일반·정예·보스 전투, 휴식·보급·상점을 `ExplorationBot`과 GUI에 연결했다. 탐사는 총 3층이며 각 층의 노드 절차는 동일하다(사용자 확인).

## 실제 앱플레이어 검증

- 환경: ADB `emulator-5554`, 1280×720 / DPI 240.
- 이전 보급 전리품 선택 화면에서 재개하여 수령·퇴장 → 일반 전투 → 정예 전투와 전리품 보상 → 지도 복귀를 확인했다. 자동 실행 입력 14회, 완료 노드 3개. 최초 보급 카드 선택은 자료 확보 과정에서 수동 입력했다.
- 보스 진입 → 전투 승리 → 전리품 수령 → 추가 영웅 보상 생략 확인 → 중심 구역 지도 복귀를 확인했다. 입력 9회, 완료 노드 1개.
- 보스 지도에서 진입 화살표 외형 차이로 입력 없이 중지했던 문제는 별도 화살표 템플릿과 초기 화면 안정화 대기로 보강했다.
- 중심 구역 첫 휴식에서 오공 3→4랭크를 확인하고 지도에 복귀했다. 입력 7회, 완료 노드 1개.
- 다음 경로가 모두 랜덤 이벤트여서 자동 실행은 진입 전에 중지했다. 별도 화면 확인으로 마력진 이벤트에 진입했고, 전투 / 전체 생명력 감소 / 영웅 이탈 선택지를 확인했다. 이후 사용자 규칙을 반영해 전투를 선택했고, 승리 후 파편 100개 및 결과 대사 뒤 지도 복귀를 확인했다.

실행 결과는 `logs/chaos_extension/run1.json`, `run3.json`, `run4.json`, 입력 전후 화면은 같은 폴더의 실행별 하위 폴더에 있다. 유지보수용 원본은 `images/chaos/node_progression/raw/`에 저장했다.

버섯 이벤트에서는 최초 판단으로 파편 100개를 소모해 무작위 전리품을 받았다. 사용자 피드백 후 최종 정책을 랭크업 → 전투 → 무작위 전리품 순으로 수정했다. 영웅 이탈·생명력 감소는 제외하고 무작위 전리품은 대안이 없을 때 허용한다. 이미 수령한 전리품은 되돌리지 않았다. 버섯 결과 대사 두 장과 전리품 팝업 닫기를 확인했다. 랭크업 선택의 실제 이벤트 결과는 다음 등장 시 검증 대상이다.

2층 보스 보상 후 3층 심층 구역 진입을 확인했다. 첫 휴식에서 오공 4→5(Max) 랭크업과 이후 일반 전투 두 번을 완료했다. 계단 이벤트는 파편 소모 확률 보상 대신 우회하여 손실 없이 통과했다.

## 자동 검증

이벤트·패배 재시작 연결 후 관련 unittest 83개 통과. 후속 상세는 [패배 및 우선순위 수정 검증](failure-restart-validation.md) 참조. 실제 저장 화면의 분류, 보스 화살표, 정예·보스 진입 분기, 전리품 선택 상태, 금지 카드와 허용 카드 혼재, 축소된 금지 이미지, 입력 직전 재검사, 자동 전투 단일 토글 및 취소를 포함한다.

상점은 제공된 전체 화면 재생 테스트로 나가기 입력 1회와 지도 복귀를 검증했다. 이번 실기 경로에서는 상점을 만나지 않아 실제 상점 퇴장 검증은 아직 하지 않았다.

## 남은 범위

- 등록되지 않은 랜덤 이벤트의 화면·선택지·결과 추가. 등록된 정책은 [이벤트 규칙](event-policy.md) 참조.
- 마지막 3층 클리어 결과 및 처음으로 돌아가 다음 회차 시작.
- 건너뛰기 버튼이 숨겨진 스토리의 최초 화면 터치 검증.
- 금지 이미지의 다양한 실제 배경·크기에 대한 추가 실기 검증.

이번 변경은 소스와 이미지 설정에 반영했으며 배포 EXE를 새로 빌드하지 않았다.

최종 실기 상태: 3층 정예 전투에서 패배 후 정산을 확인했다. 날짜 변경 안내를 제외한 실패 재시작 흐름을 구현하고, 정상 초기 화면에서 새 영웅 영입과 1층 입장을 검증했다. 최종 보스 클리어는 이번 실행에서 완료하지 못했다.
