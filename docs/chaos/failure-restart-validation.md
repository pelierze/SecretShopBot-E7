# 패배 후 재시작 및 노드 우선순위 수정

2026-09-25 사용자 확정: 전투 패배 시 결과 정산을 닫고 초기 화면으로 복귀한 다음, 지정한 영웅 구성으로 새 탐사를 자동 시작한다. 날짜 변경과 출석 안내 처리는 이번 범위에서 제외한다.

## 구현

- `FAILED` 표시를 전투 진행·승리와 구분한다. 패배 시 자동 전투를 다시 누르지 않는다.
- 패배 결과 → 별의 여정 정산 → 탐사 초기 화면 전환을 각각 확인한다.
- 초기 화면 복귀가 확인된 패배만 새 회차로 연결한다. 알 수 없는 화면 또는 복귀 실패는 재시작하지 않고 기록 후 중지한다.
- 새 회차는 기존 GUI의 영웅 설정을 유지하고 전투 초기 검증 상태를 초기화한다. 공통 중지 이벤트를 유지해 회차 전환 중에도 취소할 수 있다.
- GUI에 현재 회차와 패배 횟수를 표시한다.
- 결과 정산 화면부터 재개하여 이전 승패를 알 수 없는 경우는 초기 화면 복귀 후 중지한다. 이를 임의로 승리나 패배로 집계하지 않는다.

## 일반 전투가 정예보다 먼저 선택되지 않았던 원인

3층 지도에서 일반 전투 아이콘 자체는 검출됐으나 진입 화살표가 세로 71픽셀에 있었다. 기존 화살표 탐색 영역은 80픽셀부터 시작하여 일반 전투를 진입 후보에서 누락했다. 우선순위 배열은 올바랐지만 후보 집합이 잘못됐다.

화살표 탐색 시작점을 50픽셀로 넓혔다. 실제 문제 화면 `map_battle_elite_top_live.png`에서 일반·정예 후보를 모두 찾고 일반 전투를 선택하는 회귀 테스트를 추가했다. 이 문제로 이미 진입한 정예 전투는 패배했다. 해당 입력을 되돌린 것은 아니다.

## 검증 결과

- 관련 unittest **83개 통과**. 실제 패배 → 정산 → 초기 화면 재생 테스트, 새 회차 영웅 설정·중지 이벤트 유지, 패배 직후 중지하면 재시작하지 않는 경우, 상단 일반 전투 우선 선택을 포함한다.
- 실제 앱플레이어에서 패배 표시와 결과 정산을 확인하고 닫았다. 당시 날짜 변경 안내가 개입하여 한 번에 연속된 자동 재시작 실기는 중단됐다. 날짜 변경 처리는 사용자 요청대로 구현하지 않았다.
- 이후 정상 탐사 초기 화면에서 네 영웅 영입 → 탐사 입장을 실제 실행했다. 현재 새 회차 1층 외곽 구역 지도에 네 영웅이 모두 있으며, 재시작 검증을 마치고 자동 실행을 종료했다.
- 이번 탐사는 3층 정예 전투에서 실패했으므로 최종 보스 처치·클리어 후 반복은 검증하지 못했다.
