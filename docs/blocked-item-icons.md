# 금지 전리품 아이콘만 비교

기존 금지 전리품 검사는 OCR로 이름을 읽지 않고 이미지 템플릿을 비교한다.
하지만 등록된 세 원본에는 아이템 아이콘과 이름, 일부 설명이 함께 들어
있었다. 사용자 요청대로 원본에서 아이콘 영역만 가져와 비교하도록 변경했다.

- `dont_select_1.png`: 석판 아이콘 `(53, 7, 75, 74)`
- `dont_select_2.png`: 책 아이콘 `(69, 5, 89, 88)`
- `dont_select_3.png`: 그림 아이콘 `(40, 6, 81, 65)`

원본은 보존하며 `blocked_choice_crops`에 명시한 영역을 로드할 때 추출한다.
일치도 0.88, 색상 오차 0.18, 기존 배율 검사와 중복 검출 통합은 유지한다.
새 금지 이미지 등록 시에는 아이콘만 담은 이미지를 사용해야 한다.

아이콘만 남겨도 금지 항목을 검출하고, 이름·설명만 남기면 검출하지 않는
것을 확인한다. 카드별 제외, 전체 금지 카드 처리, 축소 아이콘, 이벤트
선택과 소모 대상의 기존 금지 항목 처리를 회귀 검사한다.
