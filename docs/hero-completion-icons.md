# 직업 아이콘으로 영입 완료 확인

2026-10-09 15:30:30 로컬 보고서에서 그림자 로제 영입은 성공했지만,
`영입 완료` 표식과 영웅 이름 이미지의 매칭 점수가 각각 0.8329와
0.7260으로 기준 0.90에 미달해 완료 확인이 시간 초과됐다.

완료 카드 오른쪽 아래의 직업 아이콘으로 완료 상태를 확인하도록 변경했다.
기사·전사·정령사·도적마다 28×28 공통 아이콘을 기존 완료 화면에서 가져오고,
각 직업 카드의 오른쪽 아래 45×45 영역 안에서만 검사한다. 일치도 기준은
0.90이다. 최신 로제 오류 화면의 방패 아이콘은 1.0000으로 매칭된다.

완료 판정은 원하는 직업 아이콘이 해당 슬롯에 있고, 같은 슬롯에 영입권의
영입 버튼이 없는 경우에 성립한다. 이름과 `영입 완료` 문구는 판정에
사용하지 않는다. 따라서 이미 영입된 영웅이 다른 영웅이어도 같은 직업의
완료 카드면 완료로 인정한다. 새로 영입할 영웅을 찾고 선택하는 단계는
기존 영웅 이미지와 금색 선택 테두리를 계속 사용한다.

네 슬롯의 아이콘이 모두 확인되어야 전체 영입 완료로 처리한다.
최신 보고서, 이름·완료 문구 가림, 잘못된 직업 아이콘, 아이콘 누락,
영입권 및 영웅 목록 화면, 같은 직업의 다른 영웅을 회귀 검사한다.
직업 아이콘 원본은 배포 목록에 명시적으로 등록하며, 최신 보고서 캡처는
테스트 자료로만 보관한다. 실제 게임에서 전체 영입과 탐사 완주는 별도
실행 확인이 필요하다.
