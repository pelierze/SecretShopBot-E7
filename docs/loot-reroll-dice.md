# 전리품 목록의 주사위 아이콘 인식

2026-10-09 17:29:09 로컬 보고서에서 정예 전투 보상 전리품 목록은
열렸지만 `다시 뽑기` 문구의 일치도 0.7867로 목록 판정이 시간 초과됐다.

사용자가 요청한 버튼 왼쪽 주사위 아이콘만 기존 원본 화면에서
`(203, 539, 28, 32)`로 가져온다. 검사 영역 `(180, 530, 930, 55)`,
일치도 0.90과 색상 오차 0.06을 유지한다. 이 범위는 우상단 재화
아이콘을 포함하지 않는다. 실제 다시 뽑기 버튼을 누르는 변경은 없다.

최신 오류 화면과 기존 일반·정예·보스·보급 전리품 화면에서 아이콘 3개가
인식된다. 문구나 가격 숫자가 없어도 인식하며, 아이콘 누락 시 목록으로
판정하지 않는다. 카드별 선택은 기존 위치 검증과 금지 전리품 검사를
유지한다. 세 아이콘이 잘못된 위치에 있으면 카드 선택을 허용하지 않는다.
실제 게임에서 전리품 선택 및 후속 진행은 추가 확인이 필요하다.
