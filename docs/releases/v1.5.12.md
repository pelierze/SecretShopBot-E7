# Epic7 Assist Bot (EAB) v1.5.12

- 자동 탐사 시작 시 영웅 목록이 열렸는데도 필터를 누르지 못하고 중지되는 문제를 수정했습니다.
- 기사·전사·정령사·도적 영입 화면을 캐릭터 이름 왼쪽의 직업 아이콘으로 구분하도록 개선했습니다. 제목 주변의 배경 차이로 정상 화면을 인식하지 못하는 상황을 줄였습니다.

## 업데이트 및 실행

v1.5.7 이상을 정상적으로 사용 중이라면 앱의 **업데이트 후 재시작** 기능으로 업데이트할 수 있습니다. 업데이트 후 실행 중이던 봇은 자동 재개하지 않습니다.

직접 설치하거나 자동 업데이트에 문제가 있다면 아래 Assets에서 `SecretShopBot-E7-v1.5.12.zip`을 내려받으세요. 실행 중인 앱을 종료하고 기존 설치 폴더와 다른 새 폴더에 압축을 푼 뒤 `SecretShopBot-E7.exe`를 실행해 주세요. 기존 바로가기를 사용한다면 새 실행 파일로 다시 만들어 주세요.
