# Epic7 Assist Bot (EAB) v1.5.2

- STOVE 캡처의 Win32 핸들 수명을 정리하고 DC·비트맵·버퍼를 재사용하도록 개선했습니다.
- STOVE 비밀상점·펭귄·장비 리롤에서 PNG 저장·재읽기 대신 메모리 프레임을 사용합니다.
- 템플릿 캐시와 비 16:9 화면의 검은 여백 계산을 최적화했습니다. 이미지 파일은 변경하지 않았습니다.
- STOVE 검색·연결 검사를 백그라운드에서 실행하고, 취소되거나 오래된 연결 결과를 적용하지 않습니다.
- 배포 파일은 런타임 허용 목록으로 수집합니다. 실행에 불필요한 안내 문서와 개발 프리뷰 스크립트를 제외하고 OCR 라이선스는 유지합니다.
- 배포 구성 검증 실패 시 ZIP 생성을 중단합니다.
- 기존 자동업데이트 호환성을 위해 EXE·ZIP 이름과 저장소 주소를 유지합니다.

검증: 관련 테스트 123개 통과, 추가 캡처 회귀 검증 통과, Windows 숨김 창 151회 캡처 시 핸들/GDI 객체 수 안정성 확인, PNG 175개 SHA256 동일 확인.
실제 STOVE 게임의 장시간 운용은 별도 확인이 필요합니다.
