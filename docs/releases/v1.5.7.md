# Epic7 Assist Bot (EAB) v1.5.7

- 자동 업데이트 후 앱을 종료했다가 다시 실행할 때 접근 권한 오류로 실행되지 않을 수 있는 문제를 수정했습니다.
- 자동 업데이트나 앱 실행 중 오류가 발생했을 때 확인할 수 있는 진단 로그를 추가했습니다. 업데이트 오류 안내에서도 로그 위치를 확인할 수 있습니다.
- 자동 탐사에서 같은 영웅을 여러 명 보유한 경우에도 영입할 영웅을 선택할 수 있도록 개선했습니다. 모험가 라스가 목록 아래쪽에 있을 때도 찾을 수 있습니다.

## 이번 버전은 수동 설치해 주세요

**현재 정상적으로 실행되는 분도 이번 버전은 아래 ZIP을 내려받아 새 폴더에 설치해 주세요.** 구버전 앱에서 자동 업데이트하면 실행 오류가 다시 발생할 수 있습니다.

1. 아래 Assets에서 `SecretShopBot-E7-v1.5.7.zip`을 다운로드합니다.
2. 실행 중인 앱을 종료하고, 기존 설치 폴더와 다른 새 폴더에 압축을 풉니다.
3. 새 폴더의 `SecretShopBot-E7.exe`를 실행합니다. 기존 바로가기를 사용 중이라면 새 실행 파일로 다시 만들어 주세요.

이 버전을 수동 설치한 뒤에는 다음 버전부터 앱의 **업데이트 후 재시작** 기능을 사용할 수 있습니다.

## 실행 오류를 제보할 때

탐색기 주소창에 `%LOCALAPPDATA%\SecretShopBot-E7\logs`를 입력하고 `updater.log`, `startup.log`를 오류 화면 및 앱 버전과 함께 보내 주세요. 이 위치에 로그가 없으면 `%TEMP%\SecretShopBot-E7\logs`도 확인해 주세요.

Windows가 실행 파일 자체를 차단하면 새 실행 로그가 남지 않을 수 있습니다. 이 경우 오류 화면과 백신 보호 기록도 함께 알려주세요.
