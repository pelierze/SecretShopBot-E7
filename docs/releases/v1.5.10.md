# Epic7 Assist Bot (EAB) v1.5.10

- 자동 탐사에서 이벤트 보상창이 랭크업 결과창으로 바뀌면 진행이 멈추던 문제를 수정했습니다. 닫기 전에 화면이 바뀐 경우 현재 화면에 맞춰 계속 진행합니다.
- 레벨업 팝업 인식을 개선해 작은 화면 크기 차이로 진행이 멈추는 상황을 줄였습니다.
- 보급 보상을 받은 뒤 레벨업·전리품·랭크업 결과창이 나타나거나 지도로 돌아오는 흐름을 처리하도록 개선했습니다.
- 자동화가 오류로 중지되면 `logs/report`에 최근 로그, 마지막 화면과 종료 사유를 자동 저장합니다. 로그에 저장 위치를 안내하므로 문제 신고 시 해당 폴더의 파일을 함께 첨부해 주세요. 정상 완료와 사용자 중지에는 보고서를 만들지 않습니다.
- 업데이트 안내창에서 새 버전의 릴리즈 노트를 읽고 설치 여부를 선택할 수 있습니다. 바로 설치하지 않으려면 **나중에**를 선택하세요.

## 오류 보고서 안내

화면을 확보할 수 없는 경우에도 최근 로그와 종료 사유를 남깁니다. 저장된 화면은 마지막으로 확인한 화면이므로 화면 캡처 실패 시 중지 직전보다 이전 화면일 수 있습니다. 강제 프로세스 종료나 전원 차단 시에는 보고서를 저장할 수 없습니다.

## 업데이트 및 실행

v1.5.7 이상을 정상적으로 사용 중이라면 앱의 **업데이트 후 재시작** 기능으로 업데이트할 수 있습니다. 업데이트 후 실행 중이던 봇은 자동 재개하지 않습니다.

v1.5.6 이하를 사용 중이거나 자동 업데이트에 문제가 있다면 아래 Assets에서 `SecretShopBot-E7-v1.5.10.zip`을 내려받으세요. 실행 중인 앱을 종료하고 기존 설치 폴더와 다른 새 폴더에 압축을 푼 뒤 `SecretShopBot-E7.exe`를 실행해 주세요. 기존 바로가기를 사용한다면 새 실행 파일로 다시 만들어 주세요.
