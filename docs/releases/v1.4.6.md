# SecretShopBot-E7 v1.4.6

## 이벤트 전투 보상 처리 수정

- 이벤트 전투 승리 후 영웅 랭크업 보상을 인식하지 못하던 문제를 수정했습니다. 사용 가능한 랭크업 보상을 계속 탐사보다 먼저 처리합니다.
- 랭크업 결과가 승리 화면의 ‘랭크업 완료’ 카드로 표시되는 경우를 지원합니다. 영웅 그림이나 이름에 의존하지 않고 공통 완료 문구를 확인합니다.
- 랭크업 후 남은 전리품 보상, 영웅 보상, 후속 대화와 지도 등 실제로 나타나는 화면을 다시 확인하여 진행합니다. 영웅 영입은 기존 파티 유지 정책을 적용합니다.
- 전투 중간부터 재개한 경우에도 보상 팝업 이후 다양한 후속 화면을 처리하도록 보완했습니다.

실제 앱플레이어에서 랭크업 보상 사용과 완료 카드, 후속 대화, 지도 복귀를 검증했습니다.

## 설치 및 업데이트

ZIP 전체를 압축 해제하여 사용하세요. v1.4.4 이상은 앱 내부 자동 업데이트를 사용할 수 있습니다.

GitHub 정식 Release에 `SecretShopBot-E7-v1.4.6.zip`과 `SecretShopBot-E7-v1.4.6.zip.sha256.txt`를 함께 첨부하세요. 태그만 푸시해서는 업데이트가 제공되지 않습니다.

실행에 필요한 이미지만 포함합니다. 사용하지 않는 수집 이미지와 테스트 자료·로그는 제외하며, 런타임에서 잘라 사용하는 원본 이미지는 포함합니다.
