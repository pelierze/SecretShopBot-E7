# Epic7 Assist Bot (EAB) v1.5.1

- 앱 표시 이름을 Epic7 Assist Bot(EAB)으로 변경했습니다.
- 기존 자동업데이트 호환성을 위해 EXE·ZIP 이름과 저장소 주소는 유지합니다.
- 사용하지 않는 OpenCV FFmpeg 영상 라이브러리를 배포에서 제외했습니다. 이미지와 OCR 모델은 그대로 유지합니다.
- 업데이트 성공 후 업데이트 프로그램이 종료되면 임시 업데이트 폴더와 이전 버전 백업을 자동 삭제합니다. 실패한 업데이트의 백업과 진단 기록은 보존합니다.
- 기존 업데이트 프로그램을 사용하는 이번 업데이트에는 이전 정리 정책이 적용됩니다. 자동 삭제는 v1.5.1 설치 후 다음 자동업데이트부터 적용됩니다.

검증: 관련 테스트 89개 통과, Windows 임시 폴더 정리 검증, FFmpeg 제외 상태의 PNG 처리·템플릿 매칭·OCR 검증.
