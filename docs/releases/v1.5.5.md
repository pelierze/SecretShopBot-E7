# Epic7 Assist Bot (EAB) v1.5.5

- STOVE 연결 설정에 `1280×720으로 맞추기` 버튼을 추가했습니다. 일반 창 모드에서 게임 화면 크기를 조정하고 적용 결과를 표시합니다. 같은 창을 사용하는 봇이 실행 중이면 조정하지 않습니다.
- 연결 설정은 상단에 고정하고, 중앙 기능 영역만 휠로 스크롤하도록 분리했습니다. 하단 로그의 스크롤과 크기 조절은 유지됩니다.
- 긴 기능 탭을 선택했을 때 하단부터 보이던 스크롤 문제를 수정했습니다. 탭 전환 시 상단부터 표시하고, 입력칸에 대한 키보드 이동 지원은 유지했습니다.

기존 매크로의 화면 인식·클릭·진행 로직은 변경하지 않았습니다. 창 크기 조정 버튼은 실제 게임 창의 크기를 바꾸며, 이후 인식과 입력은 기존 해상도 보정 로직을 사용합니다. 실제 게임에서의 창 크기 조정은 별도 확인이 필요합니다.

관련 GUI·STOVE·배포 구성 테스트 77개가 통과했습니다. 긴 탭의 내부 프레임에 포커스가 잡힐 때 하단으로 스크롤되는 현상은 수정 전 테스트에서 재현하고, 수정 후 상단 위치가 유지되는 것을 확인했습니다.
