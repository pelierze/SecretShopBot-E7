# Epic7 Assist Bot (EAB) v1.5.13

- 자동 탐사에서 영웅 선택 여부를 금색 테두리로 확인하고, 영입 완료 여부를 직업 아이콘으로 확인하도록 개선했습니다.
- 마지막으로 사용한 탐사 영웅 프리셋과 설정을 기억합니다. 같은 Windows 사용자라면 업데이트하거나 새 폴더에 설치해도 설정이 유지됩니다.
- 움직이는 레벨업 화살표와 휴식·보급·전리품 화면, 닫기 버튼을 인식하지 못해 탐사가 멈추는 상황을 줄였습니다.
- 전리품 소모 창은 빈 슬롯 안의 십자가로 확인합니다. 금지 전리품은 이름 대신 아이템 그림으로 구분합니다.
- 영웅 보상 건너뛰기와 상점 나가기 확인 창에서 진행이 멈추는 문제를 수정했습니다.
- 미래 투자 구매 확인을 개선하고, 구매 후 재화 숫자 표시가 바뀌면 구매 완료로 처리하도록 변경했습니다.
- 탐사 결과 창을 닫지 못하는 문제를 수정했습니다. 클리어와 실패·미완료를 구분하며, 실패 시에는 실패 후 반복 설정을 따릅니다.
- 이벤트 선택지는 **무작위 선택**만 제공합니다. 미리 등록된 이벤트는 정해진 선택 규칙을 따르고, 그 외 이벤트는 선택 가능한 항목 중 무작위로 고릅니다. 불리한 결과가 있는 선택지도 선택될 수 있습니다.
- 장비 다시 뽑기 기능을 앱에서 제거했습니다.

## 업데이트 및 실행

v1.5.7 이상을 정상적으로 사용 중이라면 앱의 **업데이트 후 재시작** 기능으로 업데이트할 수 있습니다. 업데이트 후 실행 중이던 봇은 자동 재개하지 않습니다.

직접 설치하거나 자동 업데이트에 문제가 있다면 아래 Assets에서 `SecretShopBot-E7-v1.5.13.zip`을 내려받으세요. 실행 중인 앱을 종료하고 기존 설치 폴더와 다른 새 폴더에 압축을 푼 뒤 `SecretShopBot-E7.exe`를 실행해 주세요. 기존 바로가기를 사용한다면 새 실행 파일로 다시 만들어 주세요.
