# SecretShopBot-E7 v1.4.3

## 상점 미래 투자 구매

- 자동 탐사에 **미래 투자만 구매 (상점마다 1회)** 옵션을 추가했습니다. 기본값은 꺼짐이며, 다른 상품과 투자금 인출은 선택하지 않습니다.
- 상품명·가격·보유 파편을 확인하고 구매 확인 창에서 상품과 금액을 다시 검증합니다. 구매 완료 표시와 파편 차감까지 확인한 뒤 퇴장합니다.
- 품절·재화 부족이면 구매를 건너뜁니다. 빨간 가격과 게임의 재화 부족 안내도 감지하며, 부족 안내 후 구매를 반복하지 않습니다.
- 상점 원본 이미지 이동에 따른 참조 경로를 수정했습니다.

## 탐사 안정성 및 배포 개선

- 보스 처치 횟수로 완주를 확인하고 목표 횟수까지 반복합니다. 패배 재도전은 완주 횟수에 포함하지 않습니다.
- 랭크업 완료를 영웅 공통 화살표와 RANK UP 문구로 확인합니다.
- 이벤트 후속 화면과 일시적인 인식 실패의 재시도를 보강했습니다.
- 수집된 이벤트를 추가해 후속 선택 단계 포함 총 41개 규칙을 제공합니다. 무작위 모드에서도 등록 규칙을 우선합니다.
- 코드·설정에서 참조하는 이미지와 런타임 등록 이미지 목록만 배포합니다. 미사용 원본·템플릿과 사용자 로그는 포함하지 않습니다.

## 실행

`SecretShopBot-E7-v1.4.3.zip`을 새 폴더에 전부 압축 해제하고 `SecretShopBot-E7.exe`를 실행하세요. `_internal` 폴더도 필요합니다. 이전 버전의 실행을 중지한 후 새 버전을 사용하세요.

앱플레이어는 1280×720, DPI 240 및 ADB 디버깅 설정을 사용합니다. 상점 자동 구매를 사용하려면 자동 탐사 탭에서 해당 옵션을 켜세요.
