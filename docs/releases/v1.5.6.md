# Epic7 Assist Bot (EAB) v1.5.6

- 자동 탐사의 기사 후보에 불속성 모험가 라스와 빛속성 자유의 기사 아로웰을 추가했습니다.
- 모든 직업에서 첫 화면에 목표 영웅이 보이지 않으면 목록을 가로로 이동하며 찾습니다. 화면 가장자리에서 이미지가 잘린 아로웰도 이동 후 선택할 수 있습니다.
- 목록을 탐색한 뒤에도 영웅이 없을 때 기존 대체 영웅 설정을 적용합니다. 이동 후에는 화면이 안정됐는지 확인하고 선택합니다.

## 다운로드와 업데이트

`SecretShopBot-E7-v1.5.6.zip`을 내려받아 압축을 풀고 `SecretShopBot-E7.exe`를 실행하세요. 기존 앱의 자동 업데이트도 사용할 수 있습니다.
