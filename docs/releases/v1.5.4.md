# Epic7 Assist Bot (EAB) v1.5.4

- 장비 리롤의 숫자 판독을 보완했습니다. 다음 리롤 전에 새 화면으로 수치를 재확인하며, 판독이 불확실하거나 결과가 서로 다르면 중지합니다. 중지 이유와 진단 기록을 남깁니다.
- 자동 탐사의 이벤트 전투 뒤 선택 화면으로 돌아왔을 때, 전투 감시가 계속 기다리다가 시간 초과로 멈추던 경로를 수정했습니다.
- README를 STOVE·앱플레이어 연결과 기능별 사용법 중심으로 정리했습니다.

## 다운로드와 업데이트

`SecretShopBot-E7-v1.5.4.zip`을 내려받아 압축을 풀고 `SecretShopBot-E7.exe`를 실행하세요. 자동 업데이트 호환성을 위해 실행 파일과 ZIP 이름을 유지했습니다. GitHub Releases에 배포할 때는 ZIP과 `.zip.sha256.txt`를 함께 올려야 합니다.

## 확인 범위

장비 리롤 관련 테스트 95개와 이벤트·노드 진행 관련 테스트 67개가 통과했습니다. 보고된 실제 게임 화면의 재현과 수정 후 장시간 동작은 별도 확인이 필요합니다. 숫자를 잘못 읽었지만 결과가 일관된 경우까지 모두 검출하는 것은 아닙니다.
