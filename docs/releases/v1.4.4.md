# SecretShopBot-E7 v1.4.4

## 앱 내부 자동 업데이트

- 새 버전 알림에서 **업데이트 후 재시작**을 선택하면 ZIP 다운로드, SHA256 검증, 파일 교체 및 재실행을 자동 처리합니다.
- 다운로드 준비가 끝난 뒤 실행 중인 봇을 중지합니다. 재시작 후 봇은 자동으로 재개하지 않습니다.
- 사용자 입력값과 선택 옵션, 로그와 업데이트 캐시를 보존합니다.
- Windows 파일 잠금에는 제한된 재시도를 적용하고, 교체 또는 새 앱 시작 실패 시 이전 파일로 복구합니다.
- `_internal`을 교체하여 이전 버전의 미사용 이미지를 남기지 않습니다.

## 최초 설치 및 배포

**v1.4.3 이하에서는 v1.4.4를 한 번 수동으로 설치해야 합니다.** 기존 앱을 종료하고 ZIP 전체를 새 폴더에 압축 해제하세요. `SecretShopBot-E7.exe`, `SecretShopBot-Updater.exe`, `_internal`을 함께 유지해야 합니다.

이후 자동 업데이트를 제공하려면 GitHub 정식 Release에 해당 버전의 ZIP과 `.zip.sha256.txt` 파일을 함께 첨부하세요. 태그만 푸시해서는 업데이트가 제공되지 않습니다.

설치 폴더와 그 상위 폴더에 쓰기 권한이 필요하며, 다운로드 후 압축 해제를 위해 여유 공간 2GB를 확인합니다. 업데이트 결과와 복구용 백업은 설치 폴더 옆 `.e7-update-*` 폴더에 보관합니다.
