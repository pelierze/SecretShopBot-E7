# Epic7 Assist Bot (EAB) v1.5.9

- 자동 탐사의 전리품 선택 화면 인식을 개선했습니다. 전리품 카드가 보이는데도 화면을 확인하지 못해 진행이 멈추는 상황을 줄였습니다.
- 전투·보급에서 전리품을 수령한 뒤 획득 결과창이 나타나면, 결과창을 닫고 다음 화면을 확인한 후 계속 탐사하거나 떠나도록 개선했습니다.
- 상점에서 미래 투자를 구매한 뒤 획득 결과창이 나타나는 경우도 처리합니다. 결과창을 닫고 구매 완료를 확인한 뒤 상점을 나갑니다.
- 상점의 구매 취소·퇴장 확인창이 닫히지 않으면 잠시 기다린 후 다시 시도합니다. 보급 획득을 다시 시도할 때도 현재 화면을 확인해 화면 전환 중의 불필요한 입력을 줄였습니다.

## 업데이트 및 실행

v1.5.7 이상을 정상적으로 사용 중이라면 앱의 **업데이트 후 재시작** 기능으로 업데이트할 수 있습니다.

v1.5.6 이하를 사용 중이거나 직접 설치하려면 아래 Assets에서 `SecretShopBot-E7-v1.5.9.zip`을 내려받으세요. 실행 중인 앱을 종료하고 기존 설치 폴더와 다른 새 폴더에 압축을 푼 뒤 `SecretShopBot-E7.exe`를 실행해 주세요. 기존 바로가기를 사용한다면 새 실행 파일로 다시 만들어 주세요.
