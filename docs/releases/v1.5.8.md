# Epic7 Assist Bot (EAB) v1.5.8

- 자동 탐사의 이벤트·휴식에서 영웅 랭크업 결과창이 닫히지 않아 진행이 멈추는 상황을 개선했습니다. 닫기 입력 뒤에도 창이 남아 있으면 잠시 기다린 후 다시 닫고, 다음 화면을 확인한 뒤 진행합니다.
- 전리품·레벨업 결과창도 닫힘을 확인하도록 개선했습니다. 화면을 확인할 수 없을 때는 추가 입력을 보내지 않으며, 결과창이 계속 남아 있으면 중지 사유에 표시합니다.
- ‘녹슨 철창’ 이벤트를 등록했습니다. ‘철창 틈으로 손을 뻗는다’를 선택해 전투를 진행합니다.

## 업데이트 및 실행

v1.5.7을 수동 설치해 사용 중이라면 앱의 **업데이트 후 재시작** 기능으로 업데이트할 수 있습니다.

v1.5.6 이하를 사용 중이거나 직접 설치하려면 아래 Assets에서 `SecretShopBot-E7-v1.5.8.zip`을 내려받으세요. 실행 중인 앱을 종료하고 기존 설치 폴더와 다른 새 폴더에 압축을 푼 뒤 `SecretShopBot-E7.exe`를 실행해 주세요. 기존 바로가기를 사용한다면 새 실행 파일로 다시 만들어 주세요.
