# Epic7 Assist Bot (EAB) v1.5.3

STOVE 자동 탐사에서 보고된 앱 프리징과 실제 마우스 이동 중 오클릭에 대응하고, 정상 동작이 확인된 1.5.1 기반으로 최적화를 재검토했습니다.

## 변경사항

- GUI 로그는 작업 스레드에서 큐로 전달하고 GUI 스레드에서 표시해 교착 가능성을 제거했습니다.
- STOVE 클릭은 목표 좌표와 누름 메시지를 연속 전송하고, 버튼을 떼기 전에 목표 좌표를 다시 전달해 실제 마우스 이동의 간섭을 줄였습니다. 실제 커서 이동이나 창 활성화는 하지 않습니다.
- 인식 템플릿 캐시에 개수·메모리 제한, 동시 접근 보호, 파일 교체·삭제·손상 감지를 추가했습니다. 화면 캡처 파일은 매번 새로 읽습니다.
- 검은 여백은 기존 계산식과 판정을 유지하면서 가장자리부터 작은 구간으로 검사합니다.
- 배포에는 실행에 필요한 ADB·OCR 자산을 명시적으로 포함하고, 문서·개발 파일을 제외합니다. 필수 실행 파일·설정·이미지 누락 시 ZIP 생성을 중단합니다.
- 1.5.2의 캡처 객체 장기 재사용, 캡처 대기 제거, 연결·캡처 스레드 변경은 재적용하지 않았습니다. 이미지 자산은 변경하지 않았습니다.

## 검증

- 관련 테스트 263개 통과. 실제 STOVE 동작과 클릭 보완은 사용자 확인을 받았습니다. 이번 최적화의 실제 게임 장시간 동작은 별도 검증이 필요합니다.
- 기존 이벤트 테스트는 종료일이 지난 설정과 누락된 테스트 이미지로 1.5.1에서도 동일한 실패가 발생합니다. 전체 테스트 통과로 표시하지 않습니다.
