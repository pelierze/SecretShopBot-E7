# Epic7 Assist Bot (EAB) v1.5.14

- 탐사의 모든 이벤트 선택지를 버튼 형태로 찾아 무작위로 선택하도록 통일했습니다. 등록된 이벤트에서도 글자나 배경 차이 때문에 선택하지 못하고 멈추는 상황을 줄였습니다.
- 금지·비활성 선택지와 취소된 선택지는 후보에서 제외합니다. 선택지 내용을 읽지 않으므로 불리한 결과가 있는 선택지도 선택될 수 있습니다.
- 전투 보상 랭크업 완료를 영웅 카드의 직업 아이콘으로 확인하도록 개선했습니다. 하단 버튼은 ‘탐사하기’ 글자만 확인합니다.
- 종료된 여름 이벤트 기능을 정리했습니다. 이벤트 탭은 유지하며 **현재 지원하는 이벤트가 없습니다** 안내를 표시합니다.

## 업데이트 및 실행

v1.5.7 이상을 정상적으로 사용 중이라면 앱의 **업데이트 후 재시작** 기능으로 업데이트할 수 있습니다. 업데이트 후 실행 중이던 봇은 자동 재개하지 않습니다.

직접 설치하거나 자동 업데이트에 문제가 있다면 아래 Assets에서 `SecretShopBot-E7-v1.5.14.zip`을 내려받으세요. 실행 중인 앱을 종료하고 기존 설치 폴더와 다른 새 폴더에 압축을 푼 뒤 `SecretShopBot-E7.exe`를 실행해 주세요. 기존 바로가기를 사용한다면 새 실행 파일로 다시 만들어 주세요. 같은 Windows 사용자의 마지막 탐사 프리셋은 유지됩니다.
