# SecretShopBot-E7 v1.4.5

## 화면과 로그 개선

- 옵션 영역을 스크롤할 수 있도록 하여 작은 모니터에서도 모든 기능을 설정할 수 있습니다.
- 하단 로그를 옵션 영역과 분리했습니다. 경계선을 드래그하여 높이를 조절하거나 로그를 확대할 수 있습니다.
- 세션별 로그 높이와 확대 상태를 저장하여 다음 실행에도 유지합니다.
- 자동 탐사의 영웅 영입 안내 문구를 줄이고, 미래 투자 구매와 무작위 이벤트 선택을 기본값으로 적용했습니다. 기존에 저장한 설정은 유지합니다.

## 자동 탐사 이벤트 처리 개선

- 이벤트 진입, 선택, 보상, 마무리 단계마다 현재 화면을 다시 판독하도록 변경했습니다.
- 여러 페이지의 대화와 전투, 전리품, 영웅 영입, 랭크업 등 다양한 후속 화면에 공통으로 대응합니다.
- 이미 등록된 이벤트는 무작위 선택 모드에서도 등록된 규칙을 우선 적용합니다.
- 전리품 소모 이벤트는 금지 전리품을 먼저 선택하고, 없으면 다른 전리품을 선택합니다. 선택 슬롯과 수량을 확인한 뒤 소모를 확정합니다.
- 같은 화면의 반복 횟수와 전체 처리 시간을 제한하여 인식 실패 시 반복 입력을 방지합니다.

실제 정령의 춤 이벤트에서 전리품 선택, 선택 슬롯·수량 확인, 소모 확정, 회복 결과와 후속 대화, 지도 복귀까지 검증했습니다.

## 설치 및 업데이트

ZIP 전체를 압축 해제하여 사용하세요. v1.4.4 이상은 앱 내부 자동 업데이트를 사용할 수 있습니다.

GitHub 정식 Release에는 `SecretShopBot-E7-v1.4.5.zip`과 `SecretShopBot-E7-v1.4.5.zip.sha256.txt`를 함께 첨부해야 합니다. 태그만 푸시해서는 업데이트가 제공되지 않습니다.

실행에 필요한 이미지만 포함하며, 사용하지 않는 수집 이미지와 테스트 자료·로그는 배포 파일에서 제외합니다. 런타임에서 잘라 사용하는 원본 이미지는 포함합니다.
