# SecretShopBot-E7 v1.4.2

## 변경 사항

- 탐사 정산에서 보스 처치 횟수를 확인해 목표 완주 횟수까지 다음 탐사를 이어갑니다. 패배는 완주 횟수에 포함하지 않으며 기존 재도전 정책을 따릅니다.
- 영웅 랭크업 완료를 공통 화살표와 RANK UP 문구로 확인합니다. 결과 화면에서 재개할 때 완료한 랭크업을 다시 사용하지 않습니다.
- 이벤트 후속 문장, 추가 선택지, 전리품·영웅·랭크업 보상 화면 처리를 보강했습니다.
- 화면 인식과 캡처가 일시적으로 실패하면 재시도하며 이전 화면의 좌표를 반복 입력하지 않습니다.
- 수집한 이벤트 9종을 추가했습니다. 후속 선택 단계 포함 등록 규칙은 총 41개입니다.
- 무작위 모드에서도 등록 이벤트는 저장 규칙을 우선합니다. 클릭 직전 등록 이벤트로 확인되면 미등록 선택 후보를 폐기합니다.
- 회차 종료 사유와 이벤트 선택 로그를 보강했습니다. 미확인 이벤트 제보용 이미지 저장은 기본적으로 꺼져 있습니다.
- 코드·설정에서 참조하지 않는 이미지를 배포에서 제외하도록 이미지 선별 절차를 강화했습니다.

## 실행 방법

`SecretShopBot-E7-v1.4.2.zip` 전체를 새 폴더에 압축 해제한 뒤 `SecretShopBot-E7.exe`를 실행하세요. `_internal` 폴더를 함께 유지해야 합니다.

앱플레이어는 1280×720, DPI 240 및 ADB 디버깅 설정을 사용합니다. 기존 실행을 중지한 뒤 새 버전을 실행하세요.

## 배포 범위

상점 자동 구매는 포함하지 않습니다. 탐사 상점은 기존처럼 구매 없이 나갑니다.

이전 실행에서 이미 초기 화면까지 복귀한 탐사의 완료 횟수는 새 실행으로 복원되지 않습니다. 이 경우 남은 목표 횟수를 입력하세요.
