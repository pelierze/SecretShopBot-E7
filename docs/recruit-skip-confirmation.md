팝업 없이 지도 등으로 바로 전환되면 확인 입력 없이 후속 상태를 반환한다.

대기 상태는 정상 완료, 시간 초과 및 중지 등의 모든 반환 경로에서 해제한다.

변경하지 않는다. 일반 전투, 이벤트 전투, 전투 랭크업 완료 화면은
같은 확인창 대기를 공유한다. 영웅 보상이 확인되지 않은 경우에는
이 문맥을 시작하지 않는다.
