# 영웅 카드의 금색 선택 테두리 확인

2026-10-09 15:16:17 로컬 오류 보고서에서 그림자 로제는 실제로 선택되어
있었으며 영입 버튼도 활성화되어 있었다. 그러나 왼쪽 상세창 이름 표식의
매칭 점수는 0.7392로 기준 0.90에 미달해 선택 확인이 시간 초과됐다.

이름 표식 대신 클릭한 카드의 금색 테두리를 확인한다. 찾은 영웅 이미지
좌표를 보관하고, 클릭 이후에는 해당 위치 주변에서 같은 영웅 이미지가
유지되는지 확인한다. 복수 사본이 있을 때 다른 카드의 선택 상태를
사용하지 않는다. 영웅 이미지는 원하는 영웅을 찾는 용도로 계속 사용한다.

1280×720 기준 공통 카드 크기와 영웅 이미지 오른쪽 끝을 기준으로 위·아래·
왼쪽 테두리를 검사한다. 각 변의 길이 중 75% 이상에서 금색 픽셀이 있어야
선택된 것으로 판단한다. 카드 내부의 금색 별이나 장식만으로 진행하지
않으며, 화면 밖으로 잘린 검사 영역은 승인하지 않는다. 상세창 이름은
선택 확인에 사용하지 않는다.

선택 테두리와 활성 영입 버튼이 연속된 관측에서 확인돼야 영입한다.
선택 테두리가 확인되지만 영입 버튼이 비활성인 경우 기존 코스트 초과
처리를 유지한다. 테두리 확인 없이 버튼만 보여도 영입하지 않는다.

실제 캡처로 지원 영웅 9종의 선택 상태, 선택 전 상태, 최신 로제 오류,
다른 사본 선택, 테두리 누락, 버튼 비활성, 관측 중 선택 상태 소실을 검증한다.
실제 게임에서 전체 영입 및 탐사 완주 확인은 별도로 필요하다.
새 오류 캡처는 회귀 자료이며 배포 리소스에는 포함하지 않는다.
