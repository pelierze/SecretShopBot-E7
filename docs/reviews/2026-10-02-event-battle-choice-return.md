사용자가 제공한 2026-10-02 로그에서 07:47:29에 미등록 이벤트 선택, 07:47:35에 전투 시작 입력, 07:47:39에 전투 화면 인식이 기록됐다. 07:52:40에는 `전투 제한 시간 초과`로 중지됐다. 사용자는 중지 후 게임이 이벤트 선택 화면에 있다고 확인했다.

전투 감시 `_battle()`는 보상·결과·지도 화면에서는 종료하지만 `event`, `unknown_event` 선택 화면은 종료 상태에 포함하지 않았다. 이 화면으로 바로 돌아오면 이벤트 처리기로 제어를 넘기지 않고 300초 제한까지 기다릴 수 있다. 현재 화면 이미지와 실행 로그 파일은 직접 읽지 못했으므로, 실제 화면의 분류 결과까지 재현한 것은 아니다.

이벤트 진행 중인 전투에서 두 선택 화면을 인식하면 전투 감시를 끝내고 기존 이벤트 흐름으로 복귀하도록 수정했다. 다음 선택은 기존 화면 재확인과 선택 정책을 거친다. 전투 제한 시간, 자동 전투 클릭 방식, 이미지 자산은 변경하지 않았다.

회귀 테스트는 전투 → 등록·미등록 선택 화면 → 지도 흐름에서 다음 이벤트 처리기가 실행되고 노드 완료가 한 번만 집계되는지 확인한다. 전투 감시 복귀 자체는 클릭을 보내지 않는다. 실제 게임 재검증과 실행 중인 배포본에 대한 수정 적용은 별도로 필요하다.
