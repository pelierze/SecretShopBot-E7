# 레벨업 이후 대기·보급 전리품 화면 미인식 점검

사용자가 제공한 2026-10-05 세션 1 로그에는 18:56:12 레벨업 팝업 닫기 입력 후 18:57:46 후속 화면 인식 시간 초과가 기록되어 있다. 영웅 랭크업 실행이나 결과 닫기 기록은 없다. 이후 두 전투에서도 레벨업 팝업 닫기 이후 인식 대기가 길어졌고, 19:02:18~20 보급 획득 버튼에 세 번 입력한 뒤 19:03:55 전리품 목록 진입 대기에서 중지했다. 첨부한 마지막 화면은 승리 화면이 아니라 전리품 세 장과 선택 버튼이 있는 화면이다. 당시 승리 화면 원본은 제공되지 않아 첫 레벨업 대기의 실제 화면을 확정할 수 없다.

1280×765 첨부 화면의 상단 창 표시줄 40픽셀을 제외하고 1280×720으로 정규화한 재현 이미지를 `images/chaos/node_progression/raw/loot_supply_selected_report_20261005.png`에 저장했다. 기존 인식기는 다시 뽑기 버튼 세 개와 오른쪽 선택 카드를 찾고도 활성 전리품 선택 버튼을 찾지 못해 화면 종류를 `None`으로 반환했다. 버튼 템플릿 비교는 상관값 약 0.899, 색상 오차 약 0.065로 기존 0.9/0.06 기준을 조금 벗어났다. 정규화 보간에 따른 소폭 차이를 감안하여 해당 활성 버튼에만 0.88/0.08 기준을 적용했다. 버튼 없는 카드 화면이나 비활성 버튼이 수령을 허용하지 않는 조건, 금지 전리품 검사, 선택 상태 재확인은 유지한다.

보급 획득 재입력은 3초를 기다린 후 여전히 보급 화면이고 완료 표시가 없을 때만 시도한다. 최신 버튼 위치를 다시 읽고 바로 다음 캡처에서도 일치해야 입력한다. 다른 화면이나 미인식 상태가 보이면 이전 보급 좌표로 재입력하지 않는다. 팝업 닫기 후 시간 초과 로그에는 마지막 화면 종류와 기대 화면 목록도 기록한다.

기존 승리 화면과 랭크업 완료 승리 화면에서는 계속 탐사 버튼이 인식된다. 레벨업 결과 → 승리 → 계속 탐사 → 지도 및 영웅 랭크업 결과 → 랭크업 완료 승리 → 계속 탐사 → 지도 경로를 이미지 기반 검사로 추가했다. 같은 랭크업 보상을 재사용하지 않고 노드를 한 번만 완료하는지 확인한다. 첨부 전리품 화면, 버튼 없는 화면, 비활성 버튼, 보급 미인식 상태의 재입력 금지와 최신 버튼 좌표 재확인도 검사한다.

새 배포본 제작과 실제 게임에서의 연속 실행은 별도 확인이 필요하다. 재현 이미지는 검사 전용이며, 새 배포 인식 템플릿으로 등록하지 않았다.

## 미래 투자 구매 후 정지 제보 및 공통 흐름 점검

같은 사용자에게서 미래 투자 구매 후에도 멈춘다는 제보가 추가됐다. 상점의 당시 화면과 로그는 제공되지 않았으므로 실제 정지 원인은 확정하지 않는다. 코드에서는 구매 확정 후 곧바로 상점의 구매 완료 표시와 파편 차감을 기다려, 중간에 인식 가능한 획득 결과 팝업이 나타나는 경로를 처리하지 않았다. 일반 전투·보급의 전리품 수령 이후에도 결과 팝업을 반환받고 원래 화면의 계속 탐사·떠나기 버튼을 기다리는 경로가 있었다.

전리품 수령과 미래 투자 구매 이후 인식 가능한 결과 팝업을 제한된 횟수 안에서 닫고 원래 화면으로 복귀하는 처리를 추가했다. 팝업 종류별 닫기 버튼과 후속 화면을 재확인한다. 공통 팝업 복귀 범위에 보급과 상점도 포함했다. 구매 완료 표시와 실제 파편 차감 확인은 유지하며, 팝업을 닫았다는 사실만으로 구매 완료를 집계하지 않는다. 구매 버튼을 재입력하지 않는다. 상점 구매 취소·퇴장 확인창도 같은 닫기 검증을 사용한다.

추가 검사는 구매 → 획득 팝업 → 구매 완료 상점 → 퇴장 → 지도, 구매 완료 표시 없는 상태에서의 중지 및 중복 구매 방지, 보급·전투 전리품 수령 팝업 후 떠나기·계속 탐사, 퇴장 확인 입력 누락 복구를 포함한다.
